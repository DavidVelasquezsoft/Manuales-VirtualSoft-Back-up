# Redes sociales

<mark style="color:$info;">Administra los enlaces a las redes sociales que serán visibles para los usuarios en la plataforma. Desde esta sección es posible agregar nuevas redes sociales y configurar la URL correspondiente para redirigir a los canales oficiales.</mark>

***

### 1. Acceso al Módulo

**Ruta de Acceso:** Site Builder > Partner > Apariencia > Redes Sociales

***

### &#x32;**. Configuraciones previas.**

Antes de realizar las acciones disponibles en la sección pop ups, es necesario contar con las siguientes configuraciones:

<table><thead><tr><th width="130">Parámetro</th><th>Descripción</th></tr></thead><tbody><tr><td><strong><code>Pais</code></strong></td><td>Indica el país para el cual se realizará la configuración</td></tr><tr><td><strong><code>Idioma</code></strong></td><td>Selecciona el idioma que se utilizará para realizar las configuraciones.</td></tr></tbody></table>

### 3. Visualización

<figure><img src="../../../.gitbook/assets/image (211).png" alt=""><figcaption><p>Figura#1: Captura de pantalla sección redes sociales</p></figcaption></figure>

### 4. Acciones disponibles

<table><thead><tr><th width="237">Acción</th><th>Descripción</th></tr></thead><tbody><tr><td><strong>Agregar (+)</strong></td><td>Crea un nuevo registro para configurar una red social.</td></tr><tr><td><strong>Seleccionar red social</strong></td><td>Define la red social que será configurada.</td></tr><tr><td><strong>Guardar</strong></td><td>Almacena la configuración realizada para la red social.</td></tr></tbody></table>

***

### 5. Configuración de Redes Sociales

Seleccione el botón **Agregar (+)** para crear un nuevo registro.

El sistema incorporará una nueva tarjeta con los campos necesarios para realizar la configuración.

<table><thead><tr><th width="150">Campo</th><th width="175">Tipo</th><th>Descripción</th></tr></thead><tbody><tr><td><strong><code>Red Social</code></strong></td><td>Lista desplegable</td><td>Selecciona la red social que será configurada. Las opciones disponibles son <strong>Facebook</strong>, <strong>Instagram</strong>, <strong>TikTok</strong>, <strong>X</strong>, <strong>YouTube</strong> y <strong>WhatsApp</strong>.</td></tr><tr><td><strong><code>URL</code></strong></td><td>Texto (URL)</td><td>Registra la dirección web correspondiente a la red social seleccionada.</td></tr></tbody></table>

***

### 6. Uso del módulo

Para agregar una nueva red social:

{% stepper %}
{% step %}
Haga clic en el botón **Agregar (+)**.
{% endstep %}

{% step %}
Seleccione la red social que desea configurar.
{% endstep %}

{% step %}
Ingrese la URL correspondiente.
{% endstep %}

{% step %}
Haga clic en **Guardar** para almacenar la configuración.
{% endstep %}
{% endstepper %}

Una vez guardados los cambios, la red social quedará disponible para su visualización en la plataforma de usuarios online.

***

### 7. Validaciones y reglas del negocio

* La URL registrada debe corresponder a la red social seleccionada.
* La configuración se almacena únicamente al hacer clic en **Guardar**.
* Los cambios realizados estarán disponibles para los usuarios una vez se guarde la configuración.
