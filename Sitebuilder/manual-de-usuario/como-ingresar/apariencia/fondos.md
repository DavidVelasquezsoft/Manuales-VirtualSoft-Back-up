# Fondos

## Configuración de fondos

Esta interfaz permite gestionar los fondos visuales de diferentes secciones de la plataforma.

**Opciones disponibles:**

* **Fondo Home:** Imagen de fondo para la página principal.
* **Fondo Torneos:** Imagen de fondo para la sección de torneos.
* **Fondo Casino:** Imagen de fondo para la sección de casino.
* **Fondo Bingos:** Imagen de fondo para la sección de bingos.
* **Fondo Sorteos:** Imagen de fondo para la sección de sorteos.

## **Cómo cambiar un fondo:**

1. **Selecciona una categoría** de fondo (Home, Torneos, Casino, Bingos o Sorteos).
2. **Ingresa la URL de la imagen** en el campo de texto en la parte inferior, o selecciónala desde el dispositivo.
3. **Haz clic en el botón "Guardar"** para aplicar el nuevo fondo.

Este proceso actualizará la imagen de fondo de la categoría seleccionada en la plataforma.

{% hint style="warning" %}
**Nota:** Si no se guarda, los cambios no serán tomados en cuenta.
{% endhint %}

## Fondos

El módulo **Fondos** permite administrar las imágenes de fondo utilizadas en las diferentes secciones de la plataforma. Desde esta sección es posible actualizar la imagen de fondo de cada categoría mediante una URL o seleccionando un archivo desde el equipo.

### 5. Uso del módulo

Para actualizar la imagen de fondo de una categoría:

{% stepper %}
{% step %}
Seleccione la categoría que desea configurar.
{% endstep %}

{% step %}
Ingrese la URL de la imagen o seleccione un archivo desde el equipo.
{% endstep %}

{% step %}
Haga clic en Guardar para aplicar la configuración.
{% endstep %}

{% step %}
Una vez almacenados los cambios, la plataforma actualizará la imagen de fondo correspondiente a la categoría seleccionada.
{% endstep %}
{% endstepper %}

{% hint style="warning" %}
**Nota:**\
Si no se selecciona la opción **Guardar**, la configuración realizada no será aplicada.
{% endhint %}

***

### 6. Validaciones y reglas del negocio

* Cada categoría admite una única imagen de fondo activa.
* La configuración se aplica únicamente a la categoría seleccionada.
* La imagen puede configurarse mediante una URL o seleccionando un archivo desde el equipo.
* Los cambios realizados se almacenan únicamente al hacer clic en **Guardar**.
* Si no se guarda la configuración, la plataforma conservará la imagen de fondo previamente configurada.
