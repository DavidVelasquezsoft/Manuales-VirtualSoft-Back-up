# Archivo de conciliación Inswitch.

{% hint style="danger" %}
**Nota**: Esta reportería ya no está en funcionamiento.
{% endhint %}

Para poder visualizar este archivo, primero es necesario pedir el acceso a dicho reporte con el área de soporte técnico, debido a que este reporte se envía automáticamente por correo electrónico de manera diaria a las 7:05 A.M. a continuación encontrarás un ejemplo de cómo debe llegar el correo.

<figure><img src="../.gitbook/assets/image (3).png" alt=""><figcaption><p>Figura #1: Captura de pantalla correo electrónico.</p></figcaption></figure>

En el archivo encontrarás una tabla con las siguientes columnas:

* **ID Usuario:** Muestra el identificador único de los usuarios incluidos en el reporte.
* **ID Depósito:** Contiene el identificador del depósito realizado por cada usuario.
* **Valor Depósito:** Indica el monto del depósito que realizó el usuario.
* **Fecha Depósito:** Registra la fecha en la que el usuario efectuó el depósito.
* **Partner:** Muestra el partner asociado con el depósito.
* **País:** Indica el país desde donde el usuario realizó el depósito.
* **ID Transacción Proveedor:** Contiene el identificador de la transacción generada por el proveedor.
* **Valor:** Especifica el monto asociado a la transacción.
* **Fecha Transacción:** Registra la fecha en la que se realizó la transacción por parte del usuario.
* **Método de Pago:** Detalla el método de pago que utilizó el usuario para completar la transacción y generar el depósito.

{% hint style="warning" %}
**Nota:** Si no se registran transacciones con el partner durante ese día, este no será incluido en el reporte.
{% endhint %}
