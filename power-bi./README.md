# Power BI

### Introducción:

Power BI es una herramienta que nos permite visualizar informes de manera dinámica a través de tableros interactivos. Gracias a sus filtros y opciones de personalización, facilita el análisis de datos y la presentación de información detallada y enfocada en necesidades específicas.

### Objetivo:

Brindar una guía completa sobre los reportes generados en Power BI, explicando su contenido, cómo acceder a ellos y utilizar sus filtros para obtener información relevante de manera eficiente.
