# Acceso a los tableros.

Una vez inicies sesión en Power BI, accederás a la pantalla de inicio, donde se presentan accesos rápidos a informes recientes, contenido recomendado y opciones para crear nuevos informes.

En el menú lateral izquierdo encontrarás una lista de módulos disponibles, entre ellos:

* **Inicio**
* **Crear**
* **Examinar**
* **Catálogo de OneLake**
* **Aplicaciones**
* **Áreas de trabajo**

Nos centraremos en el módulo **Áreas de trabajo, e**ste módulo agrupa todos los contenidos relacionados dashboards.

Para acceder, haz clic en **Áreas de trabajo** y selecciona la carpeta correspondiente por ejemplo: `Área de calidad`.
