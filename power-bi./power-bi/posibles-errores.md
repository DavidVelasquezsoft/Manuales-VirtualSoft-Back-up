# Posibles errores

| Error                                | Causa común                                                       | Solución recomendada                                                                          |
| ------------------------------------ | ----------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| Visualización vacía o sin datos      | Filtro mal aplicado o sin coincidencias                           | Revisar los filtros activos en la página y validar si hay datos que cumplan esas condiciones. |
| No se actualiza el dashboard         | Problemas con la actualización del dataset                        | Verificar programación de actualización o errores en el servicio de gateway.                  |
| Error: "Se produjo un error interno" | Problema general en el servicio Power BI o corrupción del archivo | Intentar reiniciar sesión.                                                                    |
