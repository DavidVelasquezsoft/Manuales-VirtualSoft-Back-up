# Filezilla.

### Introducción:

En este manual se explica cómo acceder y gestionar distintos reportes a través de **FileZilla**, permitiendo su descarga y revisión de manera sencilla.

### Objetivo:&#x20;

Guiar en la visualización y descarga de reportes mediante **FileZilla**, asegurando un acceso correcto y organizado a la información.
