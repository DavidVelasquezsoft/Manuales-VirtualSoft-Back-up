# Crear repositorio de casino.

Para ingresar a este repositorio, primero debes tener el acceso a el servidor, en este caso, el servidor "**Casino**" es en el que encontraremos los reportes generados, para acceder a este servidor, debes dar clic en la parte superior en el ícono de servidores, seleccionando el servidor "**Casino**"

<figure><img src="../.gitbook/assets/image (5).png" alt="" width="188"><figcaption><p>Figura #1 Captura de pantalla servidor "Casino".</p></figcaption></figure>

Al seleccionar en servidor, en el apartado derecho de FileZilla, podrás ver el repositorio de este mismo.

<figure><img src="../.gitbook/assets/image (6).png" alt="" width="563"><figcaption><p>Figura #2 Captura de pantalla Repositorio.</p></figcaption></figure>

La ruta para llegar al archivo con la información de los repositorios pagados será la siguiente:&#x20;

<figure><img src="../.gitbook/assets/image (7).png" alt=""><figcaption><p>Figura #3 Captura de pantalla Ruta.</p></figcaption></figure>

Al encontrarnos en esta ruta, podremos encontrar los reportes separados en carpetas con el nombre de los meses.

<figure><img src="../.gitbook/assets/image (8).png" alt=""><figcaption><p>Figura #4 Captura de pantalla mes.</p></figcaption></figure>

Ingresamos a la carpeta del mes correspondiente y vamos a encontrar un archivo en formato Excel llamado "reporte\_casino\_diario.csv.

<figure><img src="../.gitbook/assets/image (9).png" alt=""><figcaption><p>Figura #5 Captura de pantalla archivo Excel.</p></figcaption></figure>

Para abrir este archivo primero debes descargarlo, dándole doble clic en el nombre del archivo, Al abrirlo, encontrarás la información de los reportes generados de manera diaria por los casinos, este reporte se actualiza diariamente después de las 10:30 A.M.

* Periodo: Podrás visualizar la fecha en la que se realizó el reporte.
* ID\_Partner: Podrás ver el ID del partner.
* ID\_País: Podrás evidenciar el ID del país.
* País: Podrás evidenciar el país.
* Moneda: Podrás evidenciar la moneda con la que se generó la apuesta.
* ID\_Proveedor: Podrás evidenciar el id del proveedor con el que se realizó la apuesta.
* Nombre proveedor: Podrás evidenciar el nombre del proveedor con el que se realizó la apuesta.
* ID\_subproveedor: Podrás evidenciar el ID del subproveedor.
* Nombre\_subproveedor: Podrás evidenciar el nombre del subproveedor.
* Tipo\_casino: Podrás evidenciar el tipo de juego de casino por el cual se generó la apuesta.
* ID\_Juego: Podrás evidenciar el Id del juego en el que se realizaron las apuestas.
* Nombre\_juego: Podrás evidenciar el nombre del juego en el que se realizaron las apuestas.
* Cantidad\_Spin: Podrás evidenciar la cantidad de giros que se realizaron en el juego.
* Apuestas: Podrás evidenciar el monto de apuestas realizadas.
* Premios: Podrás evidenciar el monto en premio ganado por apuestas realizadas.
* Premios\_Bonos: Podrás evidenciar el monto total ganado por bonos.
* GGR\_bruto: Podrás evidenciar el monto de GGR bruto.
* GGR\_Neto: Podrás evidenciar el monto del GGR neto.
* Cantidad de usuarios: Podrás ver la cantidad total de usuarios que realizaron apuestas.
